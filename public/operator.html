Mode uji (?t=…): jadwal dipratinjau tanpa tunda dan semua kontrol dimatikan. Hapus ?t=… dari alamat untuk kembali ke mode nyata.
Terputus dari server. Timer tetap berjalan dengan data terakhir; perintah tidak bisa dikirim. Pastikan node server.js masih jalan.

Kedua lapangan

Geser jadwal

“+5 mnt” = jadwal mundur 5 menit (kegiatan dimulai lebih lambat). Semua layar penonton ikut berubah saat itu juga.

Tampilan layar penonton

Tema

Semua layar penonton langsung berganti. Proyektor di ruangan terang biasanya lebih jelas dengan tema Gelap.

Simulasi (uji coba)

Mulai dari

Semua layar ikut jam simulasi dan tombol operator tetap berfungsi, jadi alur lomba bisa dicoba utuh. Layar penonton menampilkan label SIMULASI. Saat dihentikan, tunda/jeda dikembalikan seperti sebelum simulasi.

Pengumuman di layar penonton

Timer per tim

Hasil stopwatch

Unduh CSV (Excel)

Tersimpan setiap kali Reset & simpan ditekan. Tim dan kegiatan diambil otomatis dari jadwal saat Start ditekan.

Nama tim

Isi nama finalis setelah penyisihan selesai. Kosongkan untuk kembali ke nama di rundown. Tersimpan otomatis.

Rundown lengkap

Jam atas = jadwal asli, jam bawah = perkiraan setelah digeser. “Mulai” = kegiatan itu dimulai sekarang di lapangannya, dan semua kegiatan sesudahnya ikut bergeser.
